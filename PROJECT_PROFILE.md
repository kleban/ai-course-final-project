## Що фіксуємо для кожного конкретного джерела

- **Ідентифікація:** сталий ID, назва, тип матеріалу або даних, автор чи постачальник.
- **Походження та доступ:** URL або шлях у проєкті, конкретний розділ чи сторінка за потреби; дата отримання, версія або дата матеріалу, якщо відома. Секрети доступу не записуємо.
- **Зміст:** які відомості або дані містить джерело, який період чи тему охоплює.
- **Роль:** для чого використовуємо — вимоги курсу, дослідження, натхнення, вхідні дані сервісу, перевірка результатів чи інша конкретна мета.
- **Зв’язок із результатом:** яку вимогу, рішення, функцію або артефакт підтримує; посилання на відповідні файли.
- **Стан перевірки:** отримано чи очікується, вивчено чи ні, що підтверджено та які питання залишилися.
- **Обмеження:** відомі прогалини, актуальність, якість даних, умови використання або доступу, якщо зазначені в джерелі. Невідомі умови позначаємо як невідомі.

## Правила оновлення

Додаємо або уточнюємо джерело після його отримання, вивчення чи зміни ролі. Фактичне використання відділяємо від запланованого. Не вигадуємо відсутні реквізити та не позначаємо невивчене джерело як перевірене.

Цей файл описує актуальний профіль і ролі джерел. Причини вибору джерел, зміни ролей та відмови від них фіксуємо також у [PROJECT_HISTORY.md](PROJECT_HISTORY.md), зберігаючи історію рішень.
