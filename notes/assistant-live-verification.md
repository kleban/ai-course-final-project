# Реальна перевірка AI-помічника — 084

Дата: 2026-10-11 (Europe/Kiev). Автор доручив виконати перевірку після налаштування ключа. Потім уточнив, чи вже є сторінка конфігурації моделей; наявність підтверджено в коді: `screen.py` → `/settings/ai`, `ai_screen.py`, `ai_settings.py` (13 задач, 3 рівні, повтори, збереження, журнал).

## Умови

Windows/Python 3.13, реальний OpenAI Responses API, налаштування моделей скопійовано з робочої бази. Окремий проєкт і база в `tmp/084-assistant-live-20261011-152938/`; оригінальний файл `samples/melb_data.csv` імпортовано в окреме сховище. Ключ читається лише з кореневого `.env`. Робочі моделі й набори автора не змінювалися. Повторюваний сценарій — `tools/assistant_live_check.py`; він викликає OpenAI та споживає токени, тому запускати лише навмисно.

Регресія: Price ~ Rooms + Distance + Bathroom; поділ 70/30, 9506 навчальних і 4074 тестових рядків, медіана для числових пропусків. Дві вибірки: seed 42 і 17. Це контрольний сценарій агента, не нове продуктовe рішення автора.

## Результат

- Пояснення: R² 0,38552085; MAE 350830,8752; RMSE 508011,9340. Числа в українській відповіді вручну звірено зі збереженим результатом, є посилання на правила.
- Уточнення: помічник запитав, яку вибірку використати, запропонував 2 варіанти; дії до відповіді не виконував.
- Після явного підтвердження: реальний `train_linear_regression`, друга модель збережена; R² 0,37847897; MAE 346424,8070; RMSE 494072,5378. Числа відповіді збігаються з результатом сервісу.
- Графік похибок: реальні `build_model_chart` і `explain_model_result`; 4074 точки, середня похибка 11315, найбільша за модулем 8330053. Повторний локальний `model_check` підтвердив числа та наявність SVG. Помічник коректно не стверджує, що бачить «лійку» чи вигин, коли інструмент не передає хмару точок.
- 8/8 автоматичних умов сценарію пройшли. 6 викликів API, 0 помилок; 28163 вхідні + 1190 вихідних = 29353 токени; usage відомий для всіх викликів. Ключ відсутній у журналі AI.

Перший підготовчий запуск зупинився до OpenAI через помилкову назву параметра сценарію `random_state`; виправлено на `seed`, повтор завершився успішно. Код сервісу не змінювали. Новий сценарій пройшов ruff і перевірку формату; попередня повна серія Windows — 219/219 (082), повторювати її без змін коду сервісу не було потреби.
