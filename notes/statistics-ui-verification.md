# Статистика — API й інтерфейс, ітерація 047

2026-10-10 (Europe/Kiev), D-57. Реалізація за погодженою
[специфікацією 0.1](../planning/subsystem-03-statistics.md); незалежний контроль
ядра — [046](statistics-core-verification.md). Ручне приймання автора попереду.

## Що додано

- «Статистика» в меню поточного проєкту, на сторінці проєкту й набору.
  Набір обирається зі списку цього проєкту; без наборів доступне завантаження.
- Окремі перегляди «Описові показники», «Пропуски», «Кореляції».
  Назви проєкту й набору, «Увесь набір», число рядків і стан метаданих видимі.
- По 10 полів на сторінці; до браузера потрапляють лише рядки потрібної сторінки.
  API допускає 1–50 полів. Для кореляцій окремо передаються назви/підписи
  придатних і обраних полів, необхідні для вибору й заголовків матриці.
- Числа показуються до 3 десяткових знаків, частки — до 2, кількості — цілі.
  Округлення лише при показі; відповіді API зберігають точність ядра.
  Дати відображаються як дати, з часом і секундами, якщо вони є в джерелі.
- Для Pearson можна звузити список полів; натискання клітинки показує
  пару, r, спільний n та причину відсутнього r. Виключені поля пояснено.
- Попередження про типи, діапазони, категорії й неоднозначні дати показано
  біля поля; зміна збережених метаданих застосовується при новому розрахунку.
- Події статистики доступні в загальному журналі; розгортаються відомості
  про набір, метод, поля, SHA-256, метадані, рядки, тривалість і помилку.

Спільний сервіс — `ProjectService.statistics`; API —
`POST /api/projects/{project_id}/statistics`, контракт `StatisticsQuery/StatisticsPage`.
Запит: dataset_id, view, необов’язкові fields, start і limit.
Результат відтворюється з оригінального файла й збережених метаданих, без кешу,
AI, нових залежностей і змін робочих даних автора.

Оформлення — розширення чинного дашборда: ті самі шрифти, палітра, іконки,
тонкі рамки без тіней та заокруглень. Для таблиць є внутрішня горизонтальна
прокрутка на вузькому екрані. Графіки й MathJax залишено на 04.

## Перевірки

Повний `tools/check.py` на Windows/Python 3.13: залежності, ruff, формат,
mypy та **79/79 тестів** успішні (77 попередніх, 2 нових перевірки API).
Нові перевірки: усі перегляди, сторінки й точні числа, попарний n,
оновлення метаданих, журнал через API, валідація запиту, ізоляція проєктів,
пошкоджений файл без розкриття приватного шляху.

Браузерний сценарій `tools/ui_smoke.py` розширено перевірками статистики.
Фінальний прогін — **63/63 сценарії**, без помилок браузера й зовнішніх запитів.
Використано окремі бази `tmp/smoke047*/data.sqlite3`, локальні Chromium і
Playwright із tmp/TEMP всередині проєкту. Робочий браузер автора не керувався.
Під час першого прогону застаріла умова копіювання очікувала один
підтверджений набір, тоді як сценарій уже підтверджував обидва; умову виправлено.
У додатковій перевірці вибору полів браузер випереджав оновлення чипів;
додано очікування після кожного видалення. Код вибору полів через це не змінювався.
