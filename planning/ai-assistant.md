# AI-помічник у процесі аналізу

Редакція 0.1, 2026-10-11 (Europe/Kiev), історія 061, D-68. Джерело: концепція автора та пропозиції агента, які автор попросив зафіксувати для презентації. Це напрям розвитку продукту, не підтверджені вимоги курсу. Панель, голос і AI-команди поки не реалізовані.

## Погоджений напрям і пропозиція інтерфейсу

Людина проходить етапи аналізу самостійно, може попросити рекомендацію, явно запустити автоматичне виконання доступної задачі та отримати пояснення результату. Немає обов'язкового AI-виклику на кожному кроці. Автор хоче показати цю взаємодію на презентації.

Пропозиція агента: одна послідовна панель «AI-помічник» у блоках із трьома діями:

- «Порадь» — рекомендація, обґрунтування, посилання на доступні правила й результати.
- «Виконай» — запуск конкретних дозволених інструментів за явною дією користувача; результат і зміни видно.
- «Поясни результат» — інтерпретація обчислень, обмеження та чернетка висновку, яку людина може редагувати.

Ці назви й компонування — зафіксована пропозиція, не завершений макет. Режим «Виконай» не повинен вимагати другого підтвердження для кожної оборотної зміни графіка, якщо користувач уже явно доручив її виконати. Нечіткі або несумісні задачі потребують уточнення; довільний код від моделі не виконується.

Таблиця описує напрям, не розширює MVP іншими моделями чи довільними графіками. Інструменти стають доступними AI лише після їх реалізації й перевірки. RAG використовується для погоджених методичних джерел, коли етап 07 готовий; до цього не імітувати пошук або джерела.

## Голосове завдання для графіка

Ідея автора: озвучити задачу, після якої перебудовується графік. Уточнення автора: розпізнавання голосу бажано виконувати компонентами браузера, без окремого виклику OpenAI для аудіо.

Пропозиція мінімального сценарію: кнопка мікрофона → коротка команда → видимий розпізнаний текст із можливістю виправлення → інтерпретація в контексті поточного набору/графіка → перевірені параметри → перебудований графік → пояснення зміни. Для першої демонстрації: «Покажи гістограму ціни з двадцятьма інтервалами» на Melbourne, де поле Price вже існує. Другий приклад: «На діаграмі розсіювання покажи ціну залежно від площі будинку» (Price/BuildingArea, з повідомленням про пропуски).

Прості фіксовані команди можуть оброблятися локальними правилами; вільне формулювання й рекомендації — через текстового AI-помічника. Голос і введений текст користуються одним виконавцем. Зміна графіка зберігає попередні налаштування для повернення; джерельні дані не змінюються. Правила стилю основної лекції застосовуються й до графіків, змінених голосом.

## Перевірені технології та межі

Перевірено документацію 2026-10-11; інтеграція, мікрофон та розпізнавання української на комп'ютері автора **не перевірялися**.

- [Web Speech API / SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition) дозволяє отримувати текст мовлення через браузер. Підтримка браузерів обмежена; реалізація може відправляти аудіо зовнішньому сервісу, тому вбудований API не означає роботу офлайн.
- [processLocally](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/processLocally) дозволяє вимагати обробку на пристрої; API експериментальний. [available()](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/available_static) перевіряє наявність локального мовного пакета. Наявність українського `uk-UA` не встановлена документацією й потребує перевірки в цільовому браузері. Завантаження мовного пакета відокремити від щоденного запуску; перед ним перевірити відповідність вимозі зберігання файлів у проєкті.
- [OpenAI function calling](https://developers.openai.com/api/docs/guides/function-calling) передає назву інструмента та аргументи застосунку; виконання відбувається нашим кодом. Це основа для текстової інтерпретації завдання з подальшою перебудовою графіка, не готова інтеграція.
- [OpenAI file transcription](https://developers.openai.com/api/docs/guides/speech-to-text) — технологічно доступна альтернатива, але після уточнення автора не є початковим обраним способом розпізнавання. Конкретної аудіомоделі не обирали й API-викликів не виконували.

Для нашої вимоги «зовнішні запити лише OpenAI» не вмикати непомітний перехід браузера на стороннє хмарне розпізнавання. Якщо локальне українське розпізнавання недоступне, залишити введення тексту й явно показати причину; інший локальний рушій або виняток для зовнішнього сервісу — окреме рішення. Доступ до мікрофона надається користувачем браузеру; секрет OpenAI лишається на сервері.

## Включення в план і готовність

Етап 06 «Модель» залишається наступним. Панель і текстові інструменти плануються на 08–09; голосова команда для одного наявного графіка — кандидат для першої демонстрації 09 після перевірки локального `uk-UA`. Постійний голосовий діалог не входить у цей мінімум.

Критерії майбутньої готовності: реальна українська команда й виправлення розпізнаного тексту; правильні поле/графік/параметри; пояснення незнайомого поля; відсутність змін при помилці; повернення попереднього графіка; робота текстового вводу без мікрофона; контроль зовнішніх запитів; журнал завдання, інструмента, результату й фактичних токенів без секретів. Політику збереження аудіо визначити до реалізації; пропозиція — не зберігати його за замовчуванням.

## Підготовка операцій моделі (063)

`src/data_story/assistant_tools.py` описує три операції моделі для майбутньої панелі: `list_training_runs` («Порадь» — контекст), `train_linear_regression` («Виконай», змінює збережені результати) і `explain_model_result` («Поясни результат», без нових обчислень). Кожна має JSON-схему аргументів у формі function calling і викликає той самий `ProjectService`, що UI та API. Детерміновані пояснення показників (`model.explain`) уже показуються в UI без AI. OpenAI, голос і сама панель не реалізовані; пропозиція агента, не погоджений остаточний контракт.

066: додано інструмент `build_model_chart` («Виконай»): будує або замінює графік перевірки моделі (регресія за ознакою, похибки, прогноз проти факту) тим самим сервісом, що UI; повертає числа й текст без SVG.

073: перший шматок панелі реалізовано — кнопка «AI» в куті й бічна панель із трьома діями на сторінках блоків проєкту, RAG-контекст, інструменти у «Виконай»; без реальної перевірки OpenAI. [Опис](subsystem-09-assistant.md).
