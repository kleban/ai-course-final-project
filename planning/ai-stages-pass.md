1. Ключ у `.env` → «Перевірити доступ» → «Пробний запит»; записати фактичні моделі й токени.
2. Реальна перевірка помічника на Melbourne: «Поясни результат» моделі, «Навчи модель» з уточнювальним питанням, «Поясни цей графік». Виправити формат function calling, якщо API відповість інакше.
3. Додати в контекст оглядового аналізу й підготовки компактні числа (статистика полів, частка пропусків), щоб поради спиралися на факти.
4. Інструменти «Виконай» для опису проєкту й метаданих — лише пропозиція з кнопкою «Застосувати».
5. Перебудова графіка командою (D-68), потім голосове введення після перевірки uk-UA у браузері.
