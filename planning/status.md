# Поточний стан

Оновлено: 2026-10-10 (Europe/Kiev), історія 028.

Data Story — локальний MVP на Python 3.13: NiceGUI + FastAPI в одному процесі, SQLite v4, pandas/openpyxl. Етап 01 прийнято; етапи 02/02b реалізовані й чекають формального приймання. Фінальний логотип автора, згорнуте меню й акцент `#174690` уже в інтерфейсі; дизайн чекає відгуку.

Поточна ітерація 028: інтегровано TOAST UI Editor у налаштування інструкцій, українські підказки, перегляд за кнопкою, локальні ресурси без CDN і без usage tracking. Перевірено 50 автотестів, ruff, формат, mypy (15 вихідних файлів), UI-смоук 28/28 із блокуванням зовнішніх запитів. Знімки в `design/reviews/028-markdown/`. Автор виконує ручний огляд; жодного автоматичного приймання від його імені немає. Попередні документні зміни 026/027 включають архітектуру DuckDB і окремий етап звітів. Коміт і пуш погоджено після інтеграції; фактичний Git-стан перевіряти окремо. Етап 03 не почато.

## Ітерація 017 — екран проєктів і запуск; етап 01 завершено

Реалізовано: NiceGUI + FastAPI в одному процесі (`web.py`), спільний сервіс і контракти (`service.py`, `contracts.py`, `validation.py`), HTTP API `/api/projects…`, `/health`, `/shutdown`; `Setup.cmd`, `Start.cmd`, `Stop.cmd`, `Check.cmd`, `tools/start.py`, `tools/check.py`; стиль і шрифти лекції в `assets/`.

Перевірено 2026-10-10 на Windows автора:

- `Check.cmd`: pip check, ruff, формат, mypy і 21 автоматичний тест — успішно.
- `Start.cmd`: сервер на 127.0.0.1:8765, браузер відкрився, порожній список.
- Браузер: створено два проєкти з однаковою українською назвою — різні ID; порожня назва дає «Назва: введіть значення.» без запису; відкриття показує поточний проєкт і журнал.
- Повторний `Start.cmd` під час роботи: другий сервер не створено, лише відкрито браузер.
- `Stop.cmd`: сервер завершився, вікно запуску закрилося, `/health` недоступний.
- Повторний `Start.cmd` після зупинки: обидва проєкти на місці; журнал показує створення й нові відкриття.

Обмеження й зауваження: `runtime/application.log` порожній — події проєктів пишуться в журнал SQLite, а файловий лог поки фіксує лише помилки сервісу; у робочій БД лишилися два тестові проєкти «Тест перезапуску — Київ» (видалення в MVP не передбачено; за потреби можна видалити файл `runtime/data-story.sqlite3` при зупиненому сервері). Сценарій «порт зайнятий чужою програмою» перевірено автотестом, не вручну. Git-коміту ще немає: усі файли не відстежені.
