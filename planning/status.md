## Модель (063, D-69)

Мінімальний блок 06 реалізовано: [специфікація 0.1](subsystem-06-model.md). Явний вибір збережених вибірок → «Навчити лінійну регресію» → тестові R²/MAE/RMSE, R² навчальної частини й MAE прогнозу середнім для порівняння, коефіцієнти з назвами, вільний член, детерміновані пояснення, попередження (лінійна залежність one-hot, мала тестова частина, перенавчання) і обмеження; формули MathJax локально. Збереження в `model_runs` (v11) з походженням; повтор повертає збережений результат; подія `model.trained` для успіху й помилки. Відмови: пошкоджений/невідповідний файл матриць, нескінченні значення, замало навчальних рядків, числова нестабільність; невизначений R² не підміняється. API `/api/projects/{id}/models`. Реєстр операцій для AI — `assistant_tools.py`. Контроль Melbourne (ізольована база): R² тест ≈ 0,442.

064 (D-70): стандартні помилки, t, p-value й зірочки значущості як у R `summary()` з приміткою; «Вільний член (a₀)»; екран розкладено блоками по 2–3 в ряд. Контроль p-value — опубліковані результати R для mtcars.
