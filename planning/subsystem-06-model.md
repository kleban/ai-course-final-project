# Модель: лінійна регресія на збережених вибірках

Редакція 0.3, 2026-10-11 (Europe/Kiev), історії 063–066. Основа — погоджений напрям D-63/D-65 (scikit-learn, явні дії людини, блок «Модель» після підготовки) і доручення автора реалізувати цілий блок 06 у мінімальному обсязі. Конкретні технічні межі нижче — деталізація агента, а не окремі рішення автора.

## Сценарій

Поточний проєкт → блок «Модель» → явний вибір збережених вибірок (етап 05) → короткий опис вибраних вибірок → кнопка «Навчити лінійну регресію» → результат: тестові R², MAE, RMSE, коефіцієнти з назвами ознак, вільний член, пояснення показників і обмежень. Відкриття екрана нічого не навчає. Результат зберігається між перезапусками й доступний у списку моделей проєкту.

## Метод

- `sklearn.linear_model.LinearRegression` з типовими параметрами (`fit_intercept=True`); власного алгоритму немає.
- Навчання (`fit`) лише на `x_train`/`y_train`; `x_test`/`y_test` використовуються тільки для прогнозу й показників.
- Показники scikit-learn: `r2_score(force_finite=False)`, `mean_absolute_error`, `root_mean_squared_error`. Для порівняння зберігаються R² на навчальній частині й MAE прогнозу середнім навчальної цілі (простий орієнтир).
- Модель не серіалізується pickle: зберігаються коефіцієнти, вільний член і параметри; прогноз відтворюється формулою.

## Непридатні дані й невизначені показники

- Вибірки читаються через перевірку власника, шляху й SHA-256 (етап 05). Додатково: наявність усіх чотирьох масивів, розмірності й кількості збігаються з документом підготовки, числовий тип, усі значення скінченні.
- Навчальних рядків має бути більше, ніж ознак + 1 (щонайменше один залишковий ступінь свободи); інакше — відмова з поясненням.
- Лінійна залежність ознак (зокрема всі категорії one-hot разом із вільним членом або стала ознака) не блокує навчання: прогноз коректний, але окремі коефіцієнти не визначені однозначно — показуємо попередження. Ранг рахується на навчальній матриці з вільним членом.
- R² не визначений, якщо всі тестові значення цілі однакові: показник не підміняється нулем чи одиницею, зберігається причина.
- Нескінченні коефіцієнти, прогнози чи показники відхиляються як числово нестабільний результат.

## Збереження й походження

Схема v11 додає `model_runs` (зв'язок із `training_runs`). Документ версії 1: оцінювач і параметри, версія scikit-learn, ID вибірок і SHA-256 матриць, ID/назва набору й SHA-256 джерела, версія метаданих, ціль/ознаки/поділ/перетворення з документа вибірок, назви ознак, коефіцієнти, вільний член, показники з причинами невизначеності, ранг, попередження й обмеження. Повторне навчання тих самих вибірок повертає збережений результат без нової події (детерміновано). Документ і успішна подія `model.trained` атомарні; помилка також записується в журнал. Журнал не містить значень клітинок.

## Значущість коефіцієнтів (064, D-70)

За вказівкою автора до коефіцієнтів додано стандартну помилку, t, p-value й позначки значущості як у `summary()` R: `***` p < 0,001, `**` < 0,01, `*` < 0,05, `.` < 0,1, без позначки ≥ 0,1; примітка з легендою й поясненням змісту p-value. Розрахунок — класичний OLS на навчальній частині (як `lm`): σ² = RSS/(n − ранг), дисперсії з псевдооберненої (XᵀX), двосторонній t-тест (scipy). Для лінійно залежних ознак статистики показуються лише для однозначно визначених (оцінюваних) коефіцієнтів, інші — «—» з причиною; при майже ідеальній підгонці p-value не показуються. Контроль — опубліковані результати R `summary(lm(mpg ~ wt, mtcars))`. Вільний член позначено «Вільний член (a₀)», формула — a₀ + a₁x₁ + … + aₚxₚ.

Екран розкладено блоками: вибірки | навчання; 4 показники; коефіцієнти | пояснення; обмеження | формули | походження; на вузьких екранах — один стовпець.

## Поза обсягом

Інші моделі, масштабування, регуляризація, крос-валідація, довірчі інтервали коефіцієнтів, робастні стандартні помилки, діагностичні графіки залишків (блок «Перевірка моделі»), автоматичне прийняття якості моделі.

## Критерії приймання

Незалежний приклад із відомими коефіцієнтами відновлюється точно (R²=1, MAE=0); зашумлений приклад збігається з незалежним розрахунком numpy `lstsq` і ручними формулами показників; fit не бачить тесту; відмови для пошкоджених/невідповідних матриць і замалої вибірки; невизначений R²; ізоляція проєктів; збереження після перезапуску; ідемпотентність; атомарний відкат; міграція v10→v11; HTTP; браузерний сценарій без зовнішніх запитів.

## Блок «Перевірка моделі» (066, D-73)

Склад за вказівкою автора, по одному графіку на тестовій частині:

1. **Графік регресії** — обрана числова ознака ↔ фактична ціль, лінія моделі; ознаки перемикаються. Інші ознаки фіксуються на середніх навчальної частини (пропозиція агента, погоджена). Під графіком — рівняння моделі (MathJax і текст) та рівняння показаної лінії.
2. **Графік похибок** — похибка (факт − прогноз) проти прогнозу з нульовою лінією.
3. **Прогноз проти факту** — з діагоналлю.

Прогнози відтворюються зі збережених коефіцієнтів і мають збігатися зі збереженим MAE, інакше відмова. Категорії (one-hot) у графіку регресії не показуються. Кожна побудова — подія `model.checked` без значень клітинок. API: POST `/api/projects/{id}/models/check` (`model_id`, `chart`, `feature`, необов'язкові `options`/`title`). Той самий виклик — інструмент `build_model_chart` для майбутнього AI, щоб замінювати/перебудовувати графіки; стиль — теми етапу 04.
