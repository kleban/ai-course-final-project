# Демонстраційні дані

`demo_apartments.csv` (UTF-8, роздільник `;`) і `demo_apartments.xlsx` (аркуш «Квартири») — **синтетичний** набір для перевірки етапу 02 і майбутньої регресії: 150 «квартир», ціна в тис. грн залежить від площі, відстані до центру, року побудови й району, з шумом і кількома пропусками. Числа вигадані й не є ринковими даними.

Згенеровано скриптом `tools/make_demo_data.py` (фіксований seed — результат відтворюваний). Справжній демонстраційний набір автор ще має вибрати.
