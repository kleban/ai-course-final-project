# Демонстраційні дані

## Основний демонстраційний набір — Melbourne Housing Snapshot

`melb_data.csv` — продажі житла в Мельбурні (січень 2016 — вересень 2017), задача — лінійна регресія ціни `Price`. Обрано автором 2026-10-10 (історія 035, D-43). Джерело, ліцензія CC BY-NC-SA 4.0 та оригінальний опис полів — [`melb_data.description.md`](melb_data.description.md); цей файл також є сирим описом для кроку 02b.

Перевірено нашим `read_table` і `profile`: UTF-8 (BOM), роздільник `,`, 13 580 рядків × 21 стовпець, повних дублікатів немає. Пропуски: `BuildingArea` 6450, `YearBuilt` 5375, `CouncilArea` 1369, `Car` 62. Категоріальні: `Type` (h/u/t), `Method` (5), `Regionname` (8), `Suburb`, `SellerG`, `CouncilArea`. Дата продажу `Date` у форматі `д/мм/рррр` — **зараз профіль визначає її як текст**, а `Postcode` — як число; це відомі обмеження етапу 02, див. `planning/status.md`.

## Синтетичний набір для автотестів

`demo_apartments.csv` (UTF-8, роздільник `;`) і `demo_apartments.xlsx` (аркуш «Квартири») — **синтетичний** набір: 150 «квартир», ціна в тис. грн залежить від площі, відстані до центру, року побудови й району, з шумом і кількома пропусками. Числа вигадані й не є ринковими даними. Згенеровано `tools/make_demo_data.py` (фіксований seed). Використовується автотестами й UI-смоуком.

## Кандидат для презентації — Seoul Bike Sharing Demand

samples/seoul_bike.csv — 8760 погодинних спостережень, 14 полів, 604168 байтів. Пропозиція агента 100; погоджено автором для презентації у 101. Джерело/ліцензія/одиниці — seoul_bike.description.md; сюжет і межі — ../notes/dataset-candidate-100.md. Оригінал збережено; для імпорту змінено лише кодування на UTF-8. Melbourne залишається погодженим основним набором.
