# Data Story — локальний аналітичний MVP

> Продовжуєте роботу в новому діалозі чи іншому агенті — почніть із [`HANDOFF.md`](HANDOFF.md).

Назва MVP — Data Story. Розробка ведеться послідовно в одному репозиторії: компонент → перевірка → наступний компонент. Сервіс для одного локального комп’ютера (Windows), без входу й облікових записів.

**Стан:** локальний MVP: проєкти, CSV/метадані, статистика й графіки, підготовка даних, лінійна регресія та перевірка, база знань, налаштування моделей AI, моніторинг і AI-помічник. Чернетки опису проєкту й метаданих застосовуються лише за кнопкою користувача. Актуальні перевірки й наступний крок — у [HANDOFF.md](HANDOFF.md). Звіти й голосова команда ще попереду.

## Як запустити (Windows)

Потрібен Python 3.13 з Windows Python Launcher (`py -3.13 --version` має працювати).

1. **Один раз і після оновлення requirements.lock:** подвійний клік `Setup.cmd` — створює `.venv` і встановлює зафіксовані залежності з `requirements.lock`. Потрібен інтернет. Якщо `.venv` уже містить актуальні залежності, крок можна пропустити.
2. **Щодня:** подвійний клік `Start.cmd` — запускає сервер і після готовності відкриває браузер на http://127.0.0.1:8765. Вікно консолі має лишатися відкритим, поки працюєте.
3. **Зупинка:** подвійний клік `Stop.cmd` (або закрити вікно `Start.cmd`).

Поведінка запуску:

- повторний `Start.cmd`, коли застосунок уже працює, не створює другий сервер — лише відкриває браузер;
- якщо порт 8765 зайнятий іншою програмою, буде зрозуміле повідомлення; чужий процес не змінюється;
- `Stop.cmd` зупиняє лише наш екземпляр (перевірка за ідентифікатором бази), інакше нічого не робить.

Дані: `runtime/data-story.sqlite3` (каталог `runtime/` виключено з Git). Сервер слухає лише 127.0.0.1.

## Перевірки

- `Check.cmd` — повний офлайн-набір: `pip check`, ruff (правила й форматування), mypy, 69 автоматичних тестів (ядро, типи й інструкції, міграція БД, контракти/API, лаунчер, іконки). Потрібне `.venv` після `Setup.cmd`.
- `tools/ui_smoke.py` — наскрізна перевірка інтерфейсу через Playwright (49 сценаріїв; див. `HANDOFF.md`).
- `Check-Projects.cmd` — лише тести (`tools/check_projects.py`), без запуску застосунку.

Для розробника: `.venv\Scripts\python.exe -B tools\check.py`; запуск без браузера: `.venv\Scripts\python.exe -B tools\start.py --no-browser`. Тимчасові тестові БД створюються в `tmp/tests/`.

## Структура

- `src/data_story/projects.py` — ядро: SQLite-сховище проєктів і журналу подій.
- `src/data_story/contracts.py`, `validation.py` — Pydantic-контракти й валідація.
- `src/data_story/service.py` — спільний сервіс і переклад помилок для UI та API.
- `src/data_story/web.py` — HTTP API `/api/projects…`, `/health`, `/shutdown`, підключення екрана.
- `src/data_story/screen.py` — сторінки: «Проєкти», «Типи проєктів» (редактор інструкцій), «Іконки», завантаження й огляд даних, опис і редагування метаданих.
- `src/data_story/project_types.py`, `instructions/*.md` — типи проєктів і типові інструкції-промпти; `configuration.py` — збережені зміни інструкцій.
- `src/data_story/storage.py` — з'єднання SQLite і міграції схеми (зараз v7).
- `src/data_story/dataset_copy.py` — етап 02c: додати наявний набір з іншого проєкту як незалежну копію разом з описами й метаданими.
- `src/data_story/data_grid.py` — «Таблиця даних» набору: AG Grid Community 34.2 (MIT), що постачається разом із NiceGUI і працює без інтернету; лише перегляд, компактні рядки, сторінки: браузер отримує з сервера лише потрібний блок, сортування й фільтри виконує сервер; українські підписи.
- `src/data_story/datasets.py` — завантаження, перевірка, збереження й профіль наборів даних; `metadata.py` — метадані (опис набору й полів); `samples/` — синтетичні демо-дані.
- `src/data_story/icons.py` — бібліотека іконок (єдине джерело) → `assets/icons.css`; галерея на сторінці «Іконки», завантаження й огляд даних, опис і редагування метаданих.
- `src/data_story/assets/style.css`, `assets/fonts/plex`, `assets/fonts/stix` — стиль і шрифти IBM Plex Sans / STIX Two Text з кирилицею (SIL OFL).
- `tools/start.py` — запуск одного процесу, виявлення повторного запуску, зупинка.
- `tests/` — автоматичні перевірки.

## Markdown у налаштуваннях

`Start.cmd` → «Типи проєктів»: TOAST UI Editor для інструкцій аналізу. Поле показує моноширинний Markdown із жирним/курсивом і кольоровим підсвічуванням; усі елементи мають однаковий розмір 14 px. Панель з іконок має українські підказки при наведенні й фокусі; нові іконки доступні в галереї. Тонка рамка об’єднує редактор; «Підказки Markdown» відкриває коротку довідку. «Перегляд» вмикає оформлений текст і початково прихований. Зберігається Markdown, ліміт — 20000 символів; доступне відновлення типової інструкції.

JavaScript, стилі й локалізація редактора збережені в репозиторії (`src/data_story/assets/vendor/toastui/`, версія 3.2.2, MIT). Редактор не потребує інтернету, usage tracking вимкнено. Для цієї зміни `Setup.cmd` не потрібен: залежності застосунку не змінені. Якщо сервіс уже працює, `Stop.cmd` → `Start.cmd`, потім оновити сторінку. Автоматичні перевірки не замінюють ручного огляду автора.

Підготовка даних (058–060): у проєкті відкрийте «Підготовка даних», оберіть набір і додайте операції над пропусками. Перегляньте результат, збережіть план і натисніть «Створити підготовлений набір». Оригінал зберігається; новий набір має власні метадані й походження.

«Вибірки для регресії»: явно оберіть ціль і ознаки, пропорцію (початково 70/30), за потреби заповнення й кодування категорій, потім «Підготувати й зберегти вибірки». Статистики заповнення й словник категорій визначаються лише на навчальній частині. Результати зберігаються між перезапусками; модель навчається окремою явною дією в блоці «Модель». Схема SQLite v14 оновлюється при запуску. Залежності scikit-learn зафіксовані в `requirements.lock`; для оновлення іншої інсталяції запустіть `Setup.cmd`.

## AI-чернетки

Налаштуйте ключ у кореневому `.env` (`OPENAI_API_KEY=…`) і моделі в «Налаштування → Моделі AI». У поточному проєкті натисніть «Чернетка опису», у наборі даних — «Чернетка метаданих» (попередньо додайте сирий опис). Перегляньте пропозицію в панелі AI й натисніть «Застосувати». Опис можна відредагувати перед застосуванням. Метадані після застосування залишаються чернеткою; перевірте їх звичайним редактором і підтвердьте окремо. AI-виклики й токени є в журналі. Незастосований перегляд зникає після перезавантаження сторінки.
