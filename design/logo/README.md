# Логотип Data Story — чернетки (застаріли)

> **Актуальний логотип — `design/logo/final/` (історія 024).** Файли нижче — чернетки історії 023.

Знак автора (з першого згенерованого варіанта: стовпчики діаграми переходять у розгорнуту книгу з хвилями) перемальовано вручну у вектор; написи — Montserrat (без засічок, як на варіантах автора): DATA — Bold `#262626`, STORY — SemiBold `#0B6BB0`, слоган «AI-powered analytics & storytelling» — Medium `#5F5F5F`. Тло прозоре. Історія 023.

| Файл | Для чого |
| --- | --- |
| `logo-horizontal.svg` | основний горизонтальний: знак + DATA STORY, слоган під ними |
| `logo-panel.svg` | ліва панель (208 px): знак + DATA / STORY у два рядки, слоган на всю ширину — **зараз у сервісі** |
| `logo-panel-stacked.svg` | альтернатива для панелі: знак зверху, назва в один рядок |
| `logo-mark.svg`, `logo-mark-simple.svg` | лише знак (з хвилями / без) |
| `logo-icon.svg` | квадратна іконка вкладки: книга зі стовпчиками — **зараз у сервісі** |
| `logo-icon-waves.svg` | квадратна іконка: книга з хвилями |
| `png/` | ті самі варіанти у PNG з прозорим тлом (великий розмір) |
| `preview-sheet.png` | усі варіанти на одному аркуші, у тому числі 16 і 32 px |
| `app-preview.png` | як виглядає ліва панель сервісу з логотипом |
| `source/` | генератор: `mark.py` (контури знака), `compose.py` (варіанти), шрифт-підмножина Montserrat (SIL OFL) |

Шрифт вбудовано в SVG як невелику підмножину гліфів, тож файли не залежать від встановлених шрифтів. Щоб замінити логотип у сервісі, досить покласти інший `logo-panel.svg` (і за потреби `logo-icon.svg`) у `src/data_story/assets/logo/` — без змін коду.
